# 🎓 EduStream – Flask-Based Learning Platform

EduStream is a dynamic web application built using Flask. It provides an online educational environment where users can view daily updated video lessons, access downloadable materials, and interact with live content uploaded by administrators.

---

## 🚀 Features

- 🔐 User authentication (registration & login)
- 📹 Daily video content streaming
- 📁 Script and image uploads by admin
- 📅 Daily updates to homepage content
- 📊 Admin dashboard for content management
- ☁️ Media storage via Firebase / S3
- 🧠 Built with Flask, Jinja, SQLAlchemy, and Bootstrap

---

## 🛠️ Tech Stack

| Layer         | Technology       |
|---------------|------------------|
| Backend       | Python + Flask   |
| Frontend      | HTML, CSS, Bootstrap, Jinja2 |
| Database      | SQLite (dev) / PostgreSQL (prod) |
| Media Storage | Firebase Storage / Amazon S3 |
| Deployment    | PythonAnywhere / Render / Railway |
